# 最佳报价 1.6.1 界面调整

本轮从已保留的 1.6.1 继续调整，游戏内安装恢复为修订后的 1.6.1，版本号保持不变。原始 1.6.1 的 DLL/PDB 和恢复脚本仍保留在 `rollback/BestOffer-1.6.1-ready/`。

## 调整内容

- 标题改为“修改快捷键”；两个按钮分别显示“面板快捷键 / 当前按键”和“诊断快捷键 / 当前按键”。
- 标题与按钮共用同一行位置和 38 单位高度，整行在上下分隔线之间垂直居中。上分隔线内沿为 552，下分隔线为 639，整行顶部为 576.5，底部为 614.5，上下留白均为 24.5 单位；文字本身也垂直居中。
- 删除原来常驻的小字。鼠标停留在标题或任一按钮上 500 毫秒后显示提示，移开立即隐藏，提示不会遮住快捷键按钮。
- 提示内容：“点击对应按钮，然后按 F1–F12 设置快捷键；按 Esc 取消。支持 Ctrl / Alt / Shift 组合键，请避免与其他模组重复。”
- 悬停提示位于按钮下方，相距 8 单位；作为临时浮层覆盖部分页脚，移开后恢复，不挤动按钮或分隔线。

# 最佳报价 / Best Offer 1.6.0

本次增加英文版，中文界面的文案与交易规则保持原样。

- **自动跟随游戏语言。** 中文游戏使用中文；英文或其他语言使用英文。游戏内切换语言后自动刷新界面、提示和到期提醒，无需重新配置模组。
- **使用游戏原版英文名称。** 物品、分类和物品特性经游戏原有本地化接口读取官方英文，即使游戏设置为日语等其他语言，模组也显示英文。读取过程不修改游戏或其他模组的语言。
- **按交易语境翻译。** 一键摆货为 Auto-fill Offer，实际卖出为 Sell This Plan，避免将摆货与成交混淆；片状耗材统一按 units 表达，超预算时明确说明放弃收取的金额。
- **英文界面排版。** 英文使用游戏西文字体，分类选择改为四列较宽卡片；中文保留原有六列布局。
- **旧规则继续生效。** 原有库存规则、分类设置与持续“全部”规则继续使用。显示名称与保存匹配名称分开，切换语言、重新进入存档或售空后补货，都不会使原有中文“全部”规则失效。
- **保留 1.5.0 回滚。** 完整包固定保存在 rollback/BestOffer-1.5.0.zip，并校验 SHA256。退出游戏后运行 scripts/Rollback.ps1 即可还原 DLL/PDB，个人配置和存档保留。

更新时退出游戏，替换 Mods/BestOffer.dll。

## English

Best Offer now follows your game language automatically: Chinese for Chinese, English for all other languages. Item, category and feature names use the game's own English localization. Existing rules and settings remain valid when switching languages, including persistent All rules from 1.5.0.

English text distinguishes placing an offer from completing a sale. Wider category cards and the game's western font improve readability. The original Chinese interface is preserved.

Exit the game and replace Mods/BestOffer.dll to update. The full source package includes a verified 1.5.0 rollback archive.

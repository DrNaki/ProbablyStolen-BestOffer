# Best Offer 1.7.3

适用于正式版原生 Mod 系统，兼容游戏 0.46D (100-REV6) / Steam build 26337366。

- 新增一键摆货快捷键（默认 Ctrl+F8）：重新计算最佳方案并摆上交易台，不自动成交。
- 新增一键售卖快捷键（默认 Ctrl+F9）：按一次直接计算并出售最佳方案，无需再次确认。
- 四项快捷键均可在游戏 Mods 齿轮或交易设置中修改，两处同步保存。均支持清除/留空禁用，重启后保留；交易设置统一归入“修改快捷键”，每项提供清除按钮。
- 修复正式版 3D 打印机输出武器被误归为“机器”内容的问题，并同步适配其他机器的独立成品输出栏。只勾选“产物”即可纳入对应成品，电池、模块、芯片和原料仍受“机器”开关控制。
- 保留完整武器与空液体输出瓶的保护；没有独立成品输出边界的混合库存仍归“机器”。

交易快捷键仅在可交易买家和原版交易平板打开时生效，仍遵守库存保护、分类规则、买家拒收和预算限制。输入、改键、暂停菜单或计算中不触发；按住按键不会重复售卖。升级时若新增默认键与已有自定义键冲突，保留旧键并禁用冲突的新键。

更新保留 UserData/BestOffer-*.json 和存档。订阅后重启游戏；手动安装时退出游戏后覆盖 Mods/BestOffer。若本地版与工坊版同时存在，游戏优先加载本地版，请同时更新或移除旧本地副本。无需 MelonLoader。

验证：219 项快捷键断言（106 场景）、493 项货源边界断言、109 项语言初始化检查，以及既有求解器/分类等回归通过；中英文界面、同步改键、清除与重启保存、摆货和直接售卖已实机检查。打印机真实输出栏识别已实机确认，其他机器布局以正式版 SDK 和 API 图测试验证，未逐台进行生产交易。

## English

- Add Auto-fill hotkey (default Ctrl+F8): calculate and place the best offer without selling.
- Add Quick Sell hotkey (default Ctrl+F9): calculate and sell the best offer immediately, without another confirmation.
- Edit all four hotkeys through the native Mods gear or Trade Settings. Both editors stay in sync. Clear any binding, or leave it empty, to disable it across restarts. Each Trade Settings binding has its own Clear button.
- Fix full-release 3D printer output weapons being classified as machine contents, and recognize other dedicated finished-output inventories. Machine Output includes finished goods; Machines still controls batteries, modules, chips and inputs.
- Keep assembled weapons intact and protect empty liquid-output bottles. Mixed inventories without a distinct finished-output boundary remain under Machines.

Trading hotkeys require a tradable buyer and the native trading tablet to be open. Inventory/category protections, buyer restrictions and budget limits still apply. They do not execute while typing, rebinding, paused or calculating. Holding a key does not repeatedly sell. Existing custom bindings are preserved; conflicting new defaults are disabled during migration.

Keep existing settings and saves. Restart after updating. Local copies override Workshop copies, so update or remove an old local copy as appropriate. No MelonLoader required.

# Best Offer 1.7.2

适用于《Probably Stolen》正式版原生 Mod 系统，兼容游戏 **0.46D (100-REV6) / Steam build 26337366**。

## 修复内容

- 修复模组在启动时过早读取游戏语言的问题：只在游戏自己的本地化与语言选择完成后读取结果，不再提前创建默认设置或同步等待资源。
- 游戏语言尚未就绪时保留模组当前语言，不将未知状态直接视为英文。
- 文本表、翻译键缺失或格式化异常时，交回游戏原生回退处理。
- 切换语言时刷新模组名称缓存，保留既有中文库存规则的身份。

报价、筛选、预算、摆货、成交与存档规则保持原有逻辑。更新保留 `UserData/BestOffer-*.json` 和存档。

已通过 109 项语言初始化、切换及隔离回归检查，以及既有求解器、分类与快捷键测试。正式版与试玩版共享源码均编译成功。测试结合游戏 SDK 静态分析与受控 API 回放，尚未在评论者的未知环境中实机复现整组症状。

## 安装与更新

Steam 订阅者更新后重新启动游戏，在 Mods 菜单按提示审核并启用。手动安装时退出游戏，将正式版包中的 `Mods/BestOffer` 合并到游戏目录，再到 Mods 菜单启用。无需 MelonLoader。若同时存在本地与工坊副本，游戏优先使用本地副本，请一并更新或移除不再使用的旧副本。

## English

- Delay language detection until the game's own localization and locale-selection operations have completed. Do not create default localization settings or synchronously wait during mod startup.
- Keep the current mod language while the game language is unavailable.
- Defer missing tables, missing keys and formatting failures to the game's fallback handling.
- Refresh cached names after language changes while preserving existing inventory-rule identities.

Trading, prices, budgets, placement, settlement and save rules are unchanged. Keep your existing settings and saves. Restart after updating. Local copies take priority over Workshop copies, so update or remove an old local copy when necessary.

Validation: 109 localization startup/switching/isolation checks plus existing solver, category and hotkey tests. Both native and legacy targets compile successfully. The full set of reported symptoms has not been reproduced in the commenters' unknown environments.

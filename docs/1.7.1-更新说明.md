# Best Offer 1.7.1 更新说明

适用于《Probably Stolen》正式版 **0.46D (100-REV6)，Steam build 26337366**，使用游戏原生 Mod 加载器。正式版与试玩版 1.6.1 的 MelonLoader DLL 不可混用。

## 正式版适配

- 按正式版新版交易平板重构库存、分类、报价方案和交易设置四页界面，支持游戏语言切换。
- 规则列表读取正式版分类数据，包含新增“改良种子”，当前共 61 项（含违禁品与赃物），并使用游戏图标。
- 保留原有报价求解、货源、库存保护、分类优先级、有效期、风险限制及玩家手动成交流程。

## 1.7.1 修复

- 主菜单 Mods / 改装件页的模组齿轮可以设置面板、诊断快捷键，与店铺交易设置即时同步。
- 支持 F1–F12 与 Ctrl、Alt、Shift 组合。无效、Esc、纯修饰键和重复组合不会覆盖旧设置。
- 调整本模组详情封面的高度与布局，为介绍文字及滚动区域保留空间。

## 安装与更新

Steam 订阅后重启游戏，在 Mods 菜单审核启用并按提示重启。Nexus 手动安装则退出游戏，将发布包内 `Mods/BestOffer` 复制到正式版游戏目录，再在 Mods 菜单启用。无需 MelonLoader。仅保留一个实际使用的副本；本地副本会优先于工坊订阅副本。

更新保留 `UserData/BestOffer-*.json`。试玩版配置可在退出两个游戏后手动迁移到正式版。发布包仅含 BestOffer.dll、manifest.xml、README、第三方说明与封面，不含个人配置、存档、游戏程序集或其他模组。

## 构建与素材

运行 `scripts/BuildWorkshop.ps1` 可生成正式版原生包，并执行求解器穷举对照、正式版分类和快捷键测试。此命令不会安装或发布。试玩版仍通过 `scripts/Build.ps1` 单独构建为 1.6.1。

`media/v1.7.1` 的图片、MP4 和 GIF 已按菜单顺序编号，中文在前、英文在后。原截图中的旧版本标记和中文方案与实际摆货数量的差异均保留并记入素材说明；素材没有修改游戏结果。

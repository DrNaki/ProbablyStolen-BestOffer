# 最佳报价 / Best Offer 1.5.0

本次扩展“分类规则”，方便按整类商品保留库存，或提前安排涨价前后的售卖计划。

**✅ 全部商品分类都能设置售卖规则**
在“分类规则”中选择商品分类，即可将整个分类设为必卖或禁卖，之后新获得的同类商品也会沿用设置。分类规则优先于“库存规则”中的单独设置；商品同时属于多个分类时，禁卖优先。再次点击已勾选的必卖／禁卖即可取消，两项都不勾选时遵循库存规则。

**✅ 可设置生效期限**
普通分类默认不限期。勾选“生效期限”中的“启用”后，可设置包含今天的生效天数，右侧立即显示到期日。剩余天数每天更新，也可随时修改；修改后从今天重新计时。临近到期时会显示“后天到期”“明天到期”。例如第 8 天设置禁卖 3 天，第 8～10 天禁卖，第 11 天解除。

**✅ 到期提醒与独立保存**
分类规则到期当天，会在“夜间报告”末尾提醒。禁卖到期后，此分类恢复按库存规则交易；必卖到期后，不再强制出售。每个分类的售卖规则和期限分别保存，同一存档下次进入时继续生效，不影响其他存档。

**✅ 分类卡片选择与违禁品／赃物快捷设置**
普通分类改为带代表物品图标的卡片选择，棕色、绿色、红色分别表示未设置、必卖、禁卖，无需逐页查找。违禁品和赃物固定显示在顶部，不设生效期限；“禁卖”可依次切换关闭、禁卖、需求例外，悬停可查看说明。

**✅ 工具箱保护与货源说明**
工具箱中的工具归入“机器”货源；未勾选“机器”时，这些工具不会被自动选作报价货源。各个“报价货源”选项均可悬停查看对应容器的简短说明。

**更新方法**
退出游戏，将主文件中的 Mods 文件夹合并到游戏根目录，替换 Mods/BestOffer.dll，避免同时保留多个版本。原有配置和库存规则会保留，无需重装加载器。

**与仓库整理共同使用**
如果同时使用 WarehouseSort 1.1.1，请同步下载可选文件“WarehouseSort 1.1.1 - BestOffer 1.5.0 Compat”，替换 Mods/WarehouseSort.dll。现有整理设置会保留，未安装 WarehouseSort 的玩家无需下载此可选文件。

适配环境：Windows x64；Probably Stolen Demo 050-Rev5-L（Steam build 26017150）；MelonLoader 0.7.3。
